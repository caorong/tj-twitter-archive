# TJ Research Daily Archive

该仓库用于归档定时任务对 [@TJ_Research](https://x.com/TJ_Research) 最近 24 小时内容的中文总结。

## 目录结构

```text
daily/YYYY/MM/YYYY-MM-DD.md
```

## 归档约定

- 每次执行覆盖运行时刻向前 24 小时；
- 归档原创帖、回复和引用帖，纯转发仅在具有分析价值时记录；
- 每篇日报保留原帖链接、发布时间、总结、投资线索与风险；
- 同一天重复执行时更新同一个文件，避免生成重复快照；
- 即使过去 24 小时没有新内容，也生成一篇明确标注“无新内容”的日报；
- 文件日期以定时任务的运行时区为准。
